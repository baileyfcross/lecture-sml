# Roadmap

Implemented in v0: repository/environment, Ollama baseline client and Modelfile, dataset schemas, explicit pedagogy configuration, versioned human-review rubric, 26 validated evaluation prompts, resumable result runner and terminal review, and a two-prompt infrastructure smoke run. The full baseline evaluation is intentionally not run yet.
