# Pedagogy

Pedagogy is represented explicitly so generation instructions, dataset metadata, and evaluation criteria can refer to the same versioned principles. The initial profile includes prior-knowledge activation, measurable objectives, connections to earlier material, concrete-to-abstract sequencing, one conceptual jump at a time, scaffolding, worked examples, guided before independent practice, formative checks, retrieval practice, misconception handling, level appropriateness, concise slides, one major idea per slide, synthesis, active learning, and explicit prerequisites.

This configuration is not scientifically complete or final. It is a practical, inspectable starting point that can evolve as teaching experience and educational research are incorporated.

Pedagogy configuration is not the same as learned instructor style. Configuration states explicit principles that should apply now; fine-tuning may later learn recurring choices such as tone, sequencing habits, example patterns, and formatting. Evaluation should score individual dimensions rather than collapsing them into a single vague quality number.
